Day 1 – Percentage Calculator 

Project Description

This is the first project of my 30 Days of Python Challenge.

The program calculates a student's overall percentage based on the marks entered for multiple subjects and generates a formatted report card.

Features

-Accepts the student's name

-Accepts the number of subjects

-Takes subject names and marks as input

-Validates marks (0–100)

-Calculates the total percentage

-Determines the highest and lowest marks

-Assigns a grade based on the percentage

-Displays a formatted report card

Python Concepts Used

-Variables

-User Input

-Lists

-Loops (`while`)

-Functions

-Conditional Statements (`if`, `elif`, `else`)

-Built-in Functions (`sum()`, `max()`, `min()`)

-String Formatting (f-strings)

Grading Criteria

|   Percentage   |   Grade   |
| -------------- | --------- |
| 90% and above  | A+        |
| 80% – 89%      | A         |
| 70% – 79%      | B         |
| 60% – 69%      | C         |
| 50% – 59%      | D         |
| Below 50%      | F         |

Sample Output

```text
========= REPORT CARD =========

Name : Mehreen

Subjects            Marks
-----------------------------
Math                95
Physics             88
English             91
-----------------------------

Highest : 95 (Math)
Lowest  : 88 (Physics)

Your percentage is 91.33%
Your grade is A+

=============================
```
