# Calculator with History

## Project Description

This is a **menu-driven calculator program built in Python** as part of my **30 Days of Python Challenge**.

The calculator performs basic mathematical operations and also keeps a history of previous calculations. It allows the user to view, clear, and back up their calculation history.

## Features

* Addition of two numbers
* Subtraction of two numbers
* Multiplication of two numbers
* Division of two numbers
* Power calculation
* Modulus calculation
* View calculation history
* Clear calculation history
* View backup of cleared history
* Input validation using `try-except`
* Handles division by zero
* Handles invalid menu choices

## Concepts Used

* Python Functions
* Global Variables
* Lists
* `while` Loops
* `if-elif-else` Conditions
* `try-except` Exception Handling
* `ValueError`
* `ZeroDivisionError`
* String Formatting
* Basic Arithmetic Operators

## How It Works

When the program starts, it displays a menu with different calculator operations.

The user can choose an operation, enter the required numbers, and get the result.

Every successful calculation is stored in the **calculation history**.

The user can also:

1. View previous calculations
2. Clear the calculation history
3. View a backup of the cleared history
4. Exit the program

## How to Run

Make sure Python is installed on your computer.

Run the following command:

```bash
python calculator.py
```

## Learning Outcome

Through this project, I practiced creating a **menu-driven Python application**, using functions to organize code, handling invalid user input with exception handling, and working with lists to maintain calculation history.

This project helped me understand how different Python concepts can be combined to create a functional console-based application.
