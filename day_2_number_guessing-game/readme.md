# Day 2 – Number Guessing Game 


## Project Description

This is the second project of my '30 Days of Python Challenge".

The program generates a random number between 1 and 100, and the player has six attempts to guess it correctly. After each guess, the program provides hints indicating whether the guess is too high or too low.

## Features

- Random number generation
- Six guessing attempts
- Input validation
- High/Low hints
- Remaining attempts counter
- Difference between the guessed and secret number
- Win/Lose messages

## Python Concepts Used

- Functions
- Loops
- Conditional Statements
- `random` module
- User Input
- Parameters
- `abs()` function

## Learning Outcomes

- Working with random numbers
- Building interactive console applications
- Improving problem-solving skills
- Organizing code using functions
