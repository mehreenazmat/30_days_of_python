# Day 4 – To-Do List

## Project Description

This is the fourth project of my **30 Days of Python Challenge**.

A console-based Python to-do list application where users can add, view, remove, complete, and clear tasks through a menu-driven interface.

## Features

* Add a new task
* View all tasks
* Remove a task
* Mark a task as completed
* Clear all tasks
* Display the number of remaining tasks
* Interactive menu
* Handles empty task lists

## Python Concepts Used

* Functions
* Lists
* `while` loops
* `if-elif-else`
* `enumerate()`
* `append()`
* `pop()`
* `clear()`
* User input
* Global variables
* Menu-driven programs
