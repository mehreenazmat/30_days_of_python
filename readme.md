# 30 Days of Python 

Welcome to my **30 Days of Python Challenge!**

After completing my Python fundamentals, I started this challenge to improve my programming and problem-solving skills by building one Python project every day. Each project introduces new concepts and increases in complexity, helping me grow from beginner to advanced through consistent practice.

## Challenge Goal

- Build one Python project every day for 30 days
- Strengthen Python programming skills
- Improve logical thinking and problem-solving
- Apply Python concepts through real-world mini projects
- Track my learning journey on GitHub

## Projects

### Day 1 – Percentage Calculator

A Python program that:

- Calculates the percentage of marks obtained
- Generates a formatted report card
- Determines the highest and lowest marks
- Assigns grades based on the calculated percentage
- Validates user input for marks

### Day 2 – Number Guessing Game

An interactive Python game where the player has six attempts to guess a randomly generated number between 1 and 100. The game provides hints after each guess and displays the difference between the guessed and secret numbers when all attempts are used.

### Day 3 – Rock Paper Scissors

An interactive Python game where the player competes against the computer for five rounds. The computer randomly selects rock, paper, or scissors, while the program validates the player's input, tracks wins, losses, and draws, and displays the final result at the end.

### Day 4 – To-Do List

A console-based Python to-do list application where users can add, view, remove, complete, and clear tasks through a menu-driven interface. The project uses functions and a list to manage tasks interactively.

More projects will be added as I continue this challenge.
