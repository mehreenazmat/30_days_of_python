# Day 7 – Student Management System

> **30 Days of Python Challenge**

## Project Description

This project is a **console-based Student Management System** developed as part of my **30 Days of Python Challenge**.

The program allows users to manage student records, including their names, roll numbers, marks, and grades through a menu-driven interface.

## Features

* Add new students
* View all student records
* Search for a student
* Remove a student
* Update student information
* Update student marks
* Automatically calculate grades
* Prevent duplicate roll numbers
* Validate marks between 0 and 100
* Show student(s) with the highest marks
* Clear all student records
* Count total students
* Handle invalid user input

## Concepts Used

* Python Functions
* Lists
* Nested Lists
* `for` Loops
* `while` Loops
* `if-elif-else` Conditions
* `global` Variables
* List Comprehension
* `max()` Function
* `len()` Function
* `any()` Function
* `enumerate()`
* Input Validation
* Exception Handling
* `try-except`
* `ValueError`

## Grading System

The program assigns grades according to the student's marks:

| Marks    | Grade |
| -------- | ----- |
| 90–100   | A+    |
| 80–89    | A     |
| 70–79    | B     |
| 60–69    | C     |
| 50–59    | D     |
| 40–49    | E     |
| Below 40 | F     |

## How to Run

Make sure Python 3.x is installed on your system.

Run the program using:

```bash
python student_management_system.py
```

## Learning Outcome

Through this project, I practiced managing collections of student data using lists and functions. I also improved my understanding of input validation, exception handling, searching, updating, deleting records, list comprehension, and finding maximum values.

This project helped me understand how multiple Python concepts can be combined to build a more structured and interactive console-based application.
